# 首页成长数值入口设计

## 目标

在首页右上角增加“活力、专注、体力”三个常驻统计入口，让用户能够看到已领取的成长总数，并在领取气泡时获得清晰但克制的归集反馈。

本期入口仅承担统计展示和领取反馈，不进入详情页，也不打开弹层。

## 设计依据

- Figma 文件：`YWDxNSWjIwRmOOQfnoyXoY`
- 目标节点：`5:58`
- 本地素材：`/Users/admin/Downloads/中田.zip`
- 素材内容：`活力.png`、`专注.png`、`体力.png`，均为 200×200 透明 PNG

Figma 中的三个入口位于首页右上角，采用纵向排列的 40×40 半透明圆角容器。标签贴近入口下缘，顺序从上到下为活力、专注、体力。

## 展示规则

每个入口绑定现有成长属性：

| 展示名称 | 数据属性 | 0 值素材 |
| --- | --- | --- |
| 活力 | `vitality` | 绿色树 |
| 专注 | `focus` | 粉绿书本 |
| 体力 | `stamina` | 黄色闪电 |

- 总数为 0 时，入口主体显示对应图标。
- 总数大于 0 时，入口主体显示数值，不同时保留图标。
- 标签始终可见，用于区分三个入口。
- 数值来自现有 `growthState.totals`，继续通过既有本地存储状态持久化。
- 入口不可点击，不使用按钮语义；统计组使用简洁的可访问名称表达当前三个数值。

## 视觉规格

- 入口沿用 Figma 的 40×40 主体尺寸、14px 圆角和半透明暖白玻璃底。
- 三个入口垂直排列，保持稳定尺寸，数值变化不得引起位移。
- 数字为 14px、中等字重、白色；标签为 11px、常规字重、深色文字。
- 标签分别使用克制的浅绿色、珍珠灰、蜂蜜黄色底色，并保留低透明白色描边。
- PNG 图标使用 `object-fit: contain`，保留素材绒感和透明边缘，不额外改色。
- 统计组不得遮挡小程序胶囊菜单、欢迎标题或任务气泡的可点击区域。

## 领取动效

采用已确认的 A 时序。

### 气泡飞行

1. 用户点击成长气泡。
2. 根据气泡的 `attribute` 找到对应统计入口。
3. 使用气泡和入口的实时边界框计算飞行位移。
4. 气泡缩小并飞向目标入口；其他入口不响应。
5. 气泡抵达后再提交领取状态并启动入口翻滚。

实时坐标替换现有按锚点写死的 `vw/vh` 位移，确保不同屏幕尺寸和气泡位置都能准确归集。

### 入口翻滚

入口使用三段式纵向翻滚：

- 已有值示例：`20 → 图标 +10 → 30`
- 0 值示例：`图标 → 图标 +10 → 10`

中间态中的 `+10` 使用该气泡实际领取值；合并气泡则显示合计值。最终值只在翻滚进入最后一段时出现。

翻滚只执行一次，不循环，不增加额外粒子或强光。图标和新增值作为同一中间画面，避免把领取反馈拆成多个漂浮层。

## 状态与并发

- `growthState` 仍是唯一持久化数据源。
- 动画临时状态不写入本地存储，仅记录目标属性、旧值、新增值和新值。
- 领取提交继续通过 `collectBubble` 完成，以保留重复奖励保护。
- 不同属性可独立播放反馈。
- 同一属性在动画未结束时收到新的领取请求，应按顺序排队，避免旧值、增量和最终值互相覆盖。
- 页面切换到私教页时不展示统计组；返回首页后直接渲染持久化总数。

## 动效降级

当 `prefers-reduced-motion: reduce` 开启时：

- 气泡不执行位移飞行。
- 领取后直接提交并更新最终数值。
- 对应入口仅做一次短暂透明度反馈，不进行翻滚。
- 不依赖 `animationend` 才能完成状态提交。

## 代码边界

- `src/growth.js`：保留现有状态模型和领取计算，不引入视觉状态。
- `src/app.js`：渲染统计入口、计算目标坐标、编排领取与翻滚时序。
- `src/styles.css`：统计入口布局、三段翻滚、气泡飞入目标和减少动态效果样式。
- `index.html`：增加统计组挂载节点。
- `assets/`：加入三个优化后的 PNG 素材，文件名使用 ASCII。

## 验证范围

- 0 值时三个入口显示正确图标。
- 非 0 值时显示持久化总数。
- 活力、专注、体力气泡分别飞向正确入口。
- 已有值和 0 值均按已确认的三段时序更新。
- 合并气泡显示合计增量且只累计一次。
- 同一属性连续领取按顺序完成。
- 减少动态效果下可立即完成领取。
- 375×812 与 402×874 视口无重叠、裁切或水平溢出。
- 私教页不显示首页统计组。
