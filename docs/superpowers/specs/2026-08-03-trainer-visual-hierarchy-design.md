# 预约私教页视觉层级调整

## 目标

在不重设计现有黑黄赛博框架的前提下，修正预约私教页的人物比例、地图清晰度、门店辅助信息和六 Tab 导航圆角层级。

## 人物 Hero

- 保留现有透明背景教练素材，不替换图片。
- 人物放大至当前尺寸的 `1.5` 倍，并整体右移、下移；头顶保留 `24–32px` 留白，右侧允许轻微出屏。
- 人物不能被 Hero 底边向下裁切。人物自然延伸到预约卡区域，再由前景卡片覆盖下半身，形成参考图的空间层次。
- 门店、身份、姓名和陪伴次数保持现有内容与左侧信息层级，不增加新文案。
- “李教练”信息模块底部与预约时间卡顶部保持 `90px` 垂直间距。
- “已陪伴训练 16 次”与“李教练”标题保持 `12px` 垂直间距。

## 地图与地标

- 地图图片完全移除 `filter` 和半透明 `opacity`，直接显示素材原色，不增加新的蒙层。
- 营业门店的地图地标继续使用黄色图钉；图钉内数字使用更深的黄色系文字并设为 `600`，确保在亮色图钉中可读。
- 闭店门店继续使用灰色图钉；图钉内数字使用深灰色并设为 `600`，不借用营业态颜色。

## 门店辅助信息

- “共 3 家”提升为清晰但次要的中性浅灰，不能与标题争抢层级。
- 每行门店右侧箭头保持中性浅灰，并在现有视觉尺寸基础上放大 `1.6` 倍。
- 不将上述信息改成黄色，黄色只用于营业状态和可操作强调。

## 底部导航

- Dock 外层只调整左上、右上圆角为 `32px`，底部仍贴合屏幕。
- 当前 Tab 的选中底使用完整正圆胶囊圆角，即 `999px`，同时包住图标和文字。
- 保持六 Tab、现有高度、横向铺满和当前中性选中底色，不重新分配导航结构。
- 选中底由一个共享胶囊承载，不在每个 Tab 内分别生成底色。
- Tab 切换时，共享胶囊沿水平方向滑到目标位置，时长约 `300ms`，末端只做一次轻微回弹，不持续晃动。
- 图标和文字颜色随选中状态同步过渡到白色。
- `prefers-reduced-motion: reduce` 下取消滑动和回弹，直接切换到目标位置。

## 响应式与验收

- 重点验证 `375x812` 与 `402x874` 两个手机尺寸。
- 人物不遮挡左侧姓名与门店信息，预约卡不遮挡人物面部和主要手臂；人物下半身由卡片覆盖而不是被 Hero 边界裁掉。
- 页面无横向溢出，最后一家门店仍能完整滚动到 Dock 上方。
- 地图无 CSS 滤镜或透明蒙层；营业地标与闭店地标能一眼区分。
- “共 3 家”和三个门店箭头在暗色背景上清晰可见，但不强于标题和营业状态。
