# 预约私教页暖炭黑视觉统一设计

## 目标

让预约私教页与首页的暖光、奶白文字、黄色强调和玻璃材质形成同一套视觉语言，同时保留训练场景需要的专业感、力量感和深色对比度。

本次只调整预约私教页的视觉色彩与材质，不改变人物、地图、布局、尺寸、预约流程、弹窗、六 Tab 结构或导航动效。

## 视觉方向

采用已确认的 A1“暖炭黑玻璃”方向。页面保持深色，但由当前冷蓝黑改为左上较暖、右下更深的斜向渐变：

```css
linear-gradient(
  135deg,
  #2a211a 0%,
  #171411 46%,
  #090b0e 100%
)
```

左上暖炭色负责衔接首页的室内暖光，中心暖黑维持页面主体，右下深黑保证底部内容与 Dock 的稳定对比。

## 色彩与材质

- 在 `.trainer-page` 内定义预约页专用 CSS 变量，避免影响首页和其他场景。
- 主文字使用暖奶白 `#fffaf3`，辅助文字使用同色的透明度层级，不继续使用偏冷的纯白灰。
- Hero 遮罩改为暖黑透明渐变，使人物自然融入背景，但不向人物肤色叠加明显黄色。
- `.booking-panel` 与 `.nearby-panel` 使用暖奶白玻璃底 `rgba(255, 248, 230, 0.075)`。
- 卡片边线使用暖白透明色 `rgba(255, 236, 200, 0.16)`，保留轻微内高光和深色投影。
- 普通日期、时间槽使用更低透明度的暖白玻璃；已占用时段继续使用灰调状态，但灰色改为偏暖的中性灰。
- 选中日期、营业状态、地图营业地标和主要操作继续使用现有黄色体系；主要按钮继续使用 `#f8d553` 到 `#e8ff66` 的渐变。
- 地图保持素材原色，不增加滤镜、透明蒙层或暖色覆盖。

## 第一张卡片强调

“选择预约时间”卡片顶部增加一条居中的水平黄色渐隐线，通过 `.booking-panel::before` 实现，不增加 HTML 元素：

- 高度：`1px`
- 宽度：卡片宽度的 `58%`
- 位置：卡片顶部水平居中
- 中心颜色：`rgba(248, 213, 83, 0.72)`
- 两端颜色：完全透明
- 不增加明显外发光
- 保留卡片原有暖白外边线

该线只强调当前主要操作区，不应用到“附近门店”卡片，也不强于日期选中态。

## Dock 与弹窗

- 预约页 Dock 改为暖棕黑 `rgba(22, 16, 13, 0.96)`，保留现有高度、顶部 `32px` 圆角、六 Tab 和共享选中胶囊动画。
- Dock 图标和文字沿用现有中性白层级，不引入新的黄色选中态。
- 预约确认弹窗的深色表面同步改为暖黑层级，按钮、结构和开合动画保持不变。
- 取消按钮继续是无底色的次操作，确认按钮继续使用黄色渐变。

## 实现边界

- 主要修改 `src/trainer-booking.css`。
- 不修改预约模型、日期数据、时段可用性、确认逻辑或页面路由。
- 不修改 `index.html` 结构，不新增装饰节点。
- 不调整人物素材、人物大小与位置、Hero 高度、卡片尺寸、地图尺寸或页面间距。
- 不调整主页面已有的视觉样式。

## 响应式与无障碍

- 在 `375x812` 与 `402x874` 两个手机视口验证。
- 暖化后正文、辅助文字、禁用时段和选中状态仍需保持可辨识的对比度层级。
- 顶部黄色渐隐线不得与卡片圆角相切或产生明显锯齿。
- 页面不得出现横向溢出，最后一家门店仍可完整滚动到 Dock 上方。
- `prefers-reduced-motion` 行为保持现状，因为本次不新增动画。

## 验收与回归

- `trainer-booking-contract` 锁定页面渐变、暖色变量、卡片玻璃、顶部黄色渐隐线和暖棕黑 Dock。
- 现有契约继续保护人物定位、地图原色、日期胶囊、确认按钮、六 Tab 与导航滑动。
- 先运行新增测试并确认因旧冷色样式而失败，再进行最小 CSS 实现并运行完整测试集。
- 浏览器验证两个手机视口的色彩层级、文本可读性、卡片边缘、地图原色和无溢出状态。
