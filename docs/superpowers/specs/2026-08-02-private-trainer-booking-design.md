# 预约私教页面设计

## 目标

在现有健身演示项目中新增“预约私教”页面。以 Figma Make 初稿压缩包 `Futuristic fitness app design.zip` 中的黑黄赛博视觉与交互框架为基础，优化信息层级和预约动线，不重新设计成另一套风格。

用户已有固定教练，页面的核心任务是在未来 7 天内选择日期和时间，然后完成预约。

## 保留的初稿框架

- 黑色与深蓝色为主的移动端视觉基底。
- 黄色作为选中、可操作和关键状态的强调色。
- 顶部大幅教练照片 Hero、渐变遮罩和底部斜切过渡。
- 玻璃质感的日期与时间预约面板。
- 附近门店地图和原有三家门店列表。
- 全宽深色六 Tab 底部导航。
- 预约确认底部弹窗和其短暂成功反馈。

## 页面信息层级

### 教练 Hero

Hero 保持沉浸式大图，但精简信息。只保留：

- `李教练`
- `已陪伴训练 16 次`
- `中田健身 · 南山旗舰店`

删除好评率、完课数、评分、认证标签和其他通用数据，避免与日期及时间选择争夺首屏注意力。Hero 中不放“立即预约”按钮。

### 预约面板

面板标题为“选择预约时间”，右侧弱化显示“未来 7 天”。

- 只展示从当天开始的未来 7 天。
- 日期不横向滚动，不提供月历或查看更远日期的入口。
- 默认选中当天，但不默认选中任何时间。
- 不提供 AI 推荐时段或推荐理由。
- 日期下方直接显示时间网格，不再增加“可约时间”次级标题。
- 已占用时段仅通过低透明度、灰调和禁用状态表达，不显示“已约”文字，不使用删除线。
- 选中时段使用黄色弱填充、黄色描边和克制的发光效果。
- 面板内不显示“已选择 周二 11:00”之类的重复摘要。

### 附近门店

完整保留初稿的地图、三个门店标记和三家附近门店列表。南山旗舰店是当前预约的固定门店，附近门店列表不改变本次预约地点或可约时段。

在完整产品中，点击其他门店应进入独立门店详情页；当前 Web Demo 不实现该页面和跳转，也不在当前页面模拟门店切换。

## 交互状态

### 初始状态

- 显示完整六 Tab 底部导航。
- 今天的日期卡处于选中状态。
- 任何时间均未选中。
- 不显示预约操作栏或其他常驻主按钮。

### 已选时间状态

点击可约时段后，六 Tab 在原位交叉淡化为预约操作栏，不在导航上方叠加第二层固定控件。

操作栏与原导航使用相同的全宽深色容器和高度：

- 左侧显示所选时间和教练摘要，例如 `周二 11:00 · 李教练`。
- 右侧为一个操作组，按顺序显示“取消”和“确认预约”。
- “取消”是透明文字按钮，不使用独立关闭图标，不将关闭操作强行放在最左边。
- “确认预约”是最右侧主操作，按钮高度为 `46px`，沿用黄色主按钮视觉。
- 点击其他可约时段只更新摘要，不重复播放操作栏进场动画。
- 点击“取消”清除时间选择，操作栏恢复为六 Tab。

### 确认弹窗

点击“确认预约”后，操作栏向上展开为初稿已有的底部确认弹窗，背景遮罩同步淡入。弹窗保留教练图片、课程、时间、地点、确认和取消操作，并做以下修正：

- 地点统一为 `中田健身 · 南山旗舰店`。
- 删除“费用”信息行。
- 删除“扣除 1 课时”和任何剩余课时信息。
- 主按钮文字为“确认预约”。
- 关闭弹窗但未预约时，返回已选时间的预约操作栏，保留已选时间。

### 预约成功

- 确认按钮按初稿交互短暂显示“预约成功”。
- 成功反馈结束后，弹窗下沉关闭，底部恢复完整六 Tab。
- 预约面板内部、日期卡片上方新增一条常驻状态行：`✓ 已预约 · 周二 11:00 · 李教练`。
- 常驻状态行位于正常文档流中，不绝对定位、不覆盖日期卡。
- 状态行出现后，日期卡、时间区和后续地址/门店内容按容器正常排版整体下移。
- 状态行使用小型勾选图标、黄色弱强调和克制分隔线，不做成另一张浮层卡片。
- 已成功预约的时间格转为灰调禁用状态，不再显示选中黄色。

## 动效

- 六 Tab 与预约操作栏使用短距离交叉淡化，避免整块底部区域突然跳变。
- 操作栏展开为弹窗时保持底边和主按钮的空间连续性。
- 日期、时间和门店列表不因底部状态切换重新入场。
- 使用系统减少动效设置时，保留状态切换但去除位移和缩放。

## 视觉与尺寸约束

- 主要演示画布为 `402×874`，并验证 `375×812`。
- 主按钮高度统一为 `46px`，水平内边距保持项目已有的 `24px`。
- 六 Tab 导航沿用当前项目的全宽深色 Dock，选中图标保持高亮白色，不恢复初稿全黄色选中态。
- 页面保持现有紧凑间距和字重体系，不增加新的数据卡、游戏化成长或 AI 推荐功能。
- 避免时间格、文字、地图标记、门店行和底部操作相互遮挡。

## 实现边界

当前项目是原生 HTML/CSS/JavaScript 演示原型。实现时应将压缩包中的 React/Tailwind 初稿视为视觉和交互参考，而不是直接替换当前项目技术栈。新页面应集成到现有六 Tab 导航中的“预约私教”入口，并保留当前主页、视频、动效和未提交改动。

当前 Demo 不包含：

- 教练选择或更换。
- AI 推荐时段。
- 月历和 7 天之外的日期。
- 课时、支付和余额。
- 门店详情页和实际跳转。
- 服务端预约、持久化或时段冲突校验。

## 验收标准

- 页面保留初稿黑黄 Hero、斜切、玻璃面板、地图、三家门店列表、六 Tab 和底部确认弹窗。
- Hero 只显示固定教练、陪伴次数和固定门店，不显示评分数据组。
- 只显示未来 7 天，无 AI 推荐，无默认时间选择。
- 无“可约时间”重复标题，无面板内“已选择”摘要。
- 已占用时段只灰调禁用，不显示“已约”文字。
- 选中时间后，六 Tab 原位切换为含“取消”和“确认预约”的操作栏，页面底部不出现双层固定控件。
- 弹窗地点为南山旗舰店，不显示费用或扣课信息。
- 预约成功后恢复六 Tab，并在日期卡片上方常驻显示预约信息，后续内容自然下移且不重叠。
- 三家附近门店完整展示，不在当前 Demo 中改变预约门店。
- `402×874` 和 `375×812` 视口中内容可滚动访问，无文字、时间格、弹窗或底部控件重叠。
- 所有现有首页状态、媒体资源和动效继续正常工作。
