# 首页问候、今日任务与成长气泡设计

## 目标

在不破坏暖木房间沉浸感的前提下，重整首页信息层级，为七项日程任务增加体力、专注、活力奖励，并建立轻量的常驻气泡领取循环。界面保持疗愈、克制，奖励反馈明确但不走重游戏化路线。

## 首页信息层级

首页继续使用全屏房间媒体作为主视觉，不增加横跨画面的进度条或底色容器。

正文从上到下排列：

1. 根据本地时间生成问候标题，例如 `下午好，Maggie`。沿用现有标题字体与约 `32px`、字重 `400` 的层级。
2. `15:30 · AI健康建议` 使用约 `11px`、字重 `400`、白色约 `58%` 不透明度，与下方建议正文保持约 `3px` 间距，作为弱化的上下文标签。
3. 建议正文沿用约 `15px`、字重 `400` 的可读层级。
4. 建议正文下方约 `8px` 显示纯文字任务进度：`今日任务 3/4，完成可获得帐篷营地`。整行使用 `12px`、字重 `400`、白色约 `82%` 不透明度和轻微文字阴影；不使用底色、容器、圆点或分段进度线。

当每日目标完成时，进度文案更新为 `今日任务 4/4，帐篷营地已获得`。进度最多显示 `4/4`，不会因继续完成其他任务变成 `5/4` 或更高。

## 每日任务与卡片

保留七项按时间排列、可横向滚动的任务卡片：

| 任务 | 奖励 |
| --- | --- |
| 08:00 补充水分 | 活力 +10 |
| 12:00 营养午餐 | 体力 +10 |
| 15:30 冥想 | 专注 +10 |
| 17:30 健康晚餐 | 体力 +10 |
| 18:30 补充水分 | 活力 +10 |
| 19:00 力量训练 | 活力 +10 |
| 22:30 睡前拉伸 | 活力 +10 |

完成任意四项任务即达到当日目标。卡片继续沿用已批准的紧凑尺寸、`4px` 间距和 `14px` 圆角：普通卡 `88 x 70px`，当前卡 `146 x 88px`，任务栏高 `98px`，下导航高 `70px`。

每张未完成卡片右上角显示对应的属性奖励角标。当前卡片的 `当前` 标签移到右下角，避免与奖励角标冲突。任务完成后卡片直接进入现有的轻量完成状态，不表达“未领取”，不增加描边、脉冲或“待领取”标签。气泡是否领取只由场景中的气泡体现。

## 气泡视觉

完成一项任务后生成一个对应属性的待领取气泡。气泡使用以下共同规格：

- 直径 `62px`。
- 主体填充为 `84%` 不透明度，并保留轻微背景模糊和内部高光。
- 属性标签 `10px`；奖励数值 `17px`、字重 `750`。
- 使用深色高对比文字，复杂背景上仍可快速辨认。
- 外圈为紧贴球体的 `2px` 同色系环形渐变，不留透明间隙。
- 环形渐变包含同色浅、中、深三个层次和一段暖白折光，并带轻微同色外发光。

属性配色：

| 属性 | 主体色 | 文字色 | 氛围 |
| --- | --- | --- | --- |
| 专注 | 珍珠灰 `#C5CEC8` | `#29342F` | 安静、清明 |
| 活力 | 日出珊瑚 `#E58A63` | `#4A2014` | 温暖、有生气 |
| 体力 | 蜂蜜黄 `#DDB64C` | `#3F310B` | 稳定、充盈 |

气泡分布在预设的场景安全锚点，避开标题与建议、角色面部、主操作按钮、任务栏和底部导航。位置在不同屏幕尺寸下按归一化坐标映射，不使用任意随机坐标。

## 气泡数量与合并

- 每项已完成任务生成一个气泡。
- 同时最多显示四个气泡。
- 第五个及后续气泡出现时，将较早的同属性气泡合并为一个气泡，显示合计值，例如两个 `活力 +10` 合并为 `活力 +20`。
- 合并只改变展示，不提前入账；合并气泡领取时一次性写入所包含奖励的总值。
- 每个底层奖励保留唯一 ID，合并和领取都必须防止重复计入。

## 常驻与领取交互

未领取气泡跨页面和会话常驻。重新进入页面时恢复到安全锚点，不重播生成动画。

常驻气泡采用异步轻浮动：

- 垂直幅度约 `3–5px`。
- 单次往返周期约 `4–6s`。
- 每颗气泡使用不同周期和负延迟，避免同步运动。
- 不使用明显横向漂移或快速弹跳。

点击或键盘领取时：

1. 气泡轻微压缩，渐变外圈短暂提亮。
2. 气泡和数值一起缩小并飞向右上角。
3. 到达右上角后直接消失，不显示到账文字、Toast 或常驻属性入口反馈。
4. 动画成功结束时将奖励写入永久属性总数并移除待领取记录。

领取操作必须幂等。动画期间禁用该气泡的重复输入；刷新或异常中断不能造成重复入账。

在 `prefers-reduced-motion: reduce` 下关闭常驻浮动和飞行动画。用户触发领取后立即完成入账，并以短淡出移除气泡。

## 数据模型与持久化

状态分为三个独立边界：

1. **当日任务状态**：以本地日期为键保存完成的任务 ID。为延续当前原型已经批准的 `3/4` 初始场景，首次创建状态时保留一个仅用于演示的基线值 `3`，不伪造已完成任务或待领取奖励；跨日后基线归零，后续展示值为 `min(基线值 + 已完成数量, 4)`。
2. **永久属性总数**：分别保存 `stamina`、`focus`、`vitality` 的累计值，不随日期清零。
3. **待领取奖励**：保存奖励 ID、来源任务 ID、属性、数值、创建时间和领取状态。场景气泡由这组记录派生。

三类状态在代码中保持独立边界，但持久化时写入一个带版本号的状态包。领取动画到达最终帧后，用一次存储写入同时更新永久总数、已领取奖励 ID 和待领取列表；写入成功后才从界面移除气泡。写入失败则恢复气泡的可领取状态。若页面在动画途中刷新，旧的待领取记录仍然存在，因此不会丢失或重复计数。

永久属性总数的数据能力在本轮实现，但其固定首页展示位置继续延后，不增加新的总数面板或入口。

如果本地存储不可用，当前会话仍可完成任务和领取奖励，但不承诺刷新或跨会话恢复。存储读写失败不得阻塞首页主要任务流程。

## 无障碍

- 每颗气泡使用原生按钮语义，名称包含属性和值，例如 `领取活力 10`。
- 支持键盘聚焦、Enter 和 Space 领取，并提供与气泡形状一致的清晰焦点环。
- 卡片奖励角标不单独接收焦点，信息合并到卡片的无障碍名称中。
- 文字和数值在三种主体色上保持足够对比度。
- 动效遵循系统减少动态效果设置。

## 范围外

- 永久属性总数在首页或其他页面的固定展示位置。
- 属性消耗、等级、兑换或排行榜机制。
- “未领取”卡片状态、到账 Toast、粒子爆炸或强游戏化反馈。
- 改变现有七项任务的时间、横向滚动结构或底部导航信息架构。

## 验证标准

- 单元测试覆盖按时间问候、七项奖励映射、每日进度 `4/4` 封顶、跨日重置和永久属性不重置。
- 单元测试覆盖待领取奖励持久化、同属性合并、合并值计算、领取幂等和刷新恢复。
- DOM 与视觉契约测试覆盖奖励角标、右下角 `当前` 标签、任务进度纯文字以及无额外进度线或容器。
- 浏览器在 `375 x 812` 和 `402 x 874` 检查气泡不遮挡标题、角色面部、主按钮、任务栏或导航。
- 浏览器验证最多四个气泡、异步轻浮动、点击飞向右上角、直接消失和数值正确入账。
- 减少动态效果模式下没有持续浮动或飞行动画，领取仍可完成。
- 刷新、页面切换和连续快速点击不会丢失奖励或重复入账。
- 浏览器控制台无新增错误。

## 验收条件

- 默认首页问候随本地时间变化，并显示用户名称 Maggie。
- AI 建议时间标签更小、更弱，并贴近建议正文。
- 首页显示无容器、无进度图形、字重 `400` 的今日任务文案。
- 七项任务使用正确的体力、专注、活力奖励角标，`当前` 标签位于当前卡右下角。
- 完成任务后生成正确颜色和数值的待领取气泡，卡片不增加未领取状态。
- 气泡外圈贴边、同色渐变并带暖白折光，不使用单一纯色环。
- 气泡保持轻微异步浮动，最多显示四个，并按规则合并溢出奖励。
- 气泡领取后飞向右上角直接消失，奖励只入账一次并永久累计。
- 本轮不新增永久属性总数的常驻展示入口。
