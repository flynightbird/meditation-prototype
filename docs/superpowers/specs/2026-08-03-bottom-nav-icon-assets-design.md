# 底部导航图标替换设计

## 目标

使用用户提供的 SVG 素材替换底部导航图标，并为 AI 教练选中态提供更强的品牌识别。保持现有六等分导航、70px 高度、半透明选中底托和导航行为不变。

## 素材映射

| 导航项 | 未选中 | 选中 |
| --- | --- | --- |
| AI 教练 | 保留现有机器人图标 | `AI教练.svg` |
| 预约私教 | `约教练-off.svg` | `约教练-on.svg` |
| Skill | `skill-off.svg` | `skill-on.svg` |
| 训练计划 | `健身计划-off.svg` | `健身计划-on.svg` |
| 积分 | `积分-off.svg` | `积分-on.svg` |
| 我的 | `我的-off.svg` | `我的-on.svg` |

`头部.svg` 本次不使用。

## 视觉规则

- 所有 SVG 均直接使用素材内置颜色，不使用 CSS 蒙版、滤镜或路径重着色。
- 五个普通导航项的 on/off 图标均以 `28px × 28px` 展示。
- 普通导航项继续显示文字；选中后仅切换为对应 on 素材，文字沿用现有选中样式。
- AI 教练未选中时继续显示现有机器人图标和“AI教练”文字。
- AI 教练选中时显示 `44px × 44px` 小马素材并隐藏文字。
- AI 小马保持在原有六等分导航项内居中。44px 静止尺寸和约 47.5px 的回弹峰值均不得越出 54px 高的底托内部区域。
- 现有半透明选中底托保留，仍随当前导航项移动。

## 动效

- on/off 图标切换使用约 `140ms` 的轻微淡入。
- 切换到 AI 教练时，小马播放一次约 `420ms` 的缩放回弹：`0.82 → 1.08 → 1`。
- 小马在选中停留期间不循环动画。
- 切离 AI 教练时直接恢复机器人图标和文字，不播放反向回弹。
- `prefers-reduced-motion: reduce` 下取消回弹和淡入，仅保留即时状态切换。

## 实现边界

- 将已确认的 SVG 复制到项目 `assets/`，不直接引用桌面路径。
- 使用当前 `.nav-item.is-active` 状态控制 on/off 素材显示，不新增导航状态模型。
- 保留现有 `aria-current`、按钮名称和点击行为；装饰图标继续对辅助技术隐藏。
- 不调整底部导航高度、六等分宽度、标签文案或其他页面布局。

## 验收标准

- 六个导航项在未选中与选中状态下显示正确图标。
- 所有素材保持其原始 SVG 颜色。
- AI 教练选中时只有 44px 小马，没有文字；切离后机器人和文字恢复。
- 375px 与 402px 宽手机视口下，小马回弹不越出底托，不挤压相邻导航项。
- 回弹只在进入 AI 教练时触发一次，减少动态效果下无缩放动画。
- 现有导航、私教页面和成长气泡测试继续通过。
