# 冥想控制区按钮与底座设计

## 目标

将冥想进行中的暂停与结束控制改为两个独立圆形图标按钮，并在按钮下方使用与现有底部导航一致的全宽深色毛玻璃底座。倒计时、提示语、视频播放流程和其他页面布局保持不变。

## 视觉设计

- 控制底座贴合视口底部并占满应用宽度，高约 `110px`。
- 底座复用 `.bottom-nav` 的视觉语言：`rgba(20, 13, 9, 0.72)` 背景、`blur(18px) saturate(1.2)` 毛玻璃、顶部半透明细描边，以及 `22px 22px 0 0` 顶部圆角。
- 两个 `64px × 64px` 圆形按钮在底座内水平居中，间距约 `12px`。
- 左侧按钮使用黄色背景和黑色图标；右侧按钮使用白色背景和黑色图标。
- 图标使用用户提供的 `pause.svg`、`play.svg` 和 `stop.svg`，在按钮内以 `24px × 24px` 显示。
- 按钮提供按压反馈和清晰的键盘焦点态。

## 交互设计

- 冥想进行中，左侧按钮显示暂停图标，触发已有 `pause` 动作。
- 冥想暂停后，左侧按钮切换为播放图标，再次触发同一动作以继续。
- 右侧按钮始终显示停止图标，触发已有 `end` 动作。
- 图标按钮使用随状态更新的中文 `aria-label`；暂停状态继续保留 `aria-pressed`。
- 不修改状态机、计时逻辑和媒体播放控制。

## 实现范围

- 将三枚 SVG 复制到项目 `assets/` 目录。
- 修改 `src/app.js` 中活动态控制区的标记，使用图标和无障碍名称。
- 修改 `src/styles.css` 中 `.session-controls` 及其按钮样式，并调整活动态 `.action-zone` 使底座全宽贴底。
- 更新 `tests/visual-contract.test.js` 的视觉契约，不改动其他功能模块。

## 验证

- 先添加并运行视觉契约测试，确认它因旧控制区实现而失败。
- 完成最小实现后运行完整 `npm test`。
- 启动本地服务后使用 `agent-browser` 验证开始、暂停、继续与停止流程。
- 在 `402 × 874` 和 `375 × 812` 视口截图，检查按钮尺寸、间距、底座贴边、安全区、图标切换以及内容无重叠。

## 非目标

- 不修改计时环、冥想文案、视频素材或完成后的奖励流程。
- 不调整普通首页底部导航的现有样式。
- 不引入新的状态或动画系统。
