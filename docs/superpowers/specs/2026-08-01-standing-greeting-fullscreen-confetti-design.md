# 站姿调整、打招呼与全屏散花设计

## 目标

恢复冥想完成后的“小马站姿调整”视频，并让它完整播放后再进入“小马打招呼”奖励阶段。同时将帐篷解锁时的小范围散花扩大为一次性全屏散花，强化完成反馈，不改变帐篷领取与晚餐转场流程。

## 状态与媒体

媒体状态保持现有单视频层和状态机边界：

1. `active`：播放 `video-meditation.mp4`，维持 20 秒演示倒计时。
2. `completion`：从头有声播放一次恢复后的 `video-meditation-complete.mp4`，不循环。
3. `reward`：完成视频结束后切换到 `video-greeting.mp4`，从头播放并整段循环；帐篷气泡和散花在该状态进入时同步出现。
4. `reward-settled`：继续整段循环 `video-greeting.mp4`，帐篷落地，底部卡片与导航按现有时间线出现。
5. `meal-prep`：领取满 5 秒后按现有暖光交叉淡化切换到晚餐准备视频。

视频加载失败时继续使用现有静态客厅回退机制。新流程不恢复任何末尾切片或 `tailSeconds` 逻辑。

## 全屏散花

- 奖励进入时集中播放一次，目标时长约 1.8 秒，不持续到用户领取。
- 粒子层覆盖完整 402×874 画布，并兼容 375×812。
- 粒子从画布上方和左右上方分散落入，横向覆盖全宽，结束位置覆盖中下部，避免只围绕帐篷气泡。
- 使用约 24–32 个轻量 CSS 粒子，通过尺寸、颜色、旋转、水平漂移、延迟和下落距离形成自然层次。
- 保持当前治愈配色，以暖黄、柔白和少量浅蓝为主，不增加高饱和彩纸或爆炸效果。
- 粒子层不接收指针事件，层级位于视频上方、主要文字和帐篷领取气泡下方，确保内容可读且领取可点击。
- `prefers-reduced-motion: reduce` 下继续隐藏散花，不以静态粒子遮挡画面。

## 保持不变

- 帐篷气泡的位置、尺寸和“点击领取”交互。
- 领取后帐篷落地与“静心帐篷已放入营地”提示。
- 约 1.5 秒后底部任务卡和导航进场。
- 领取满 5 秒后暖光交叉淡化到晚餐准备视频。
- 晚餐卡当前状态、卡片尺寸及后续演示逻辑。

## 验证标准

- 自动测试验证 `completion` 使用站姿调整视频且只播放一次，`reward` 与 `reward-settled` 使用打招呼视频并整段循环。
- 源码中不存在奖励视频末尾切片逻辑。
- 402×874 与 375×812 浏览器流程中，两个视频按顺序播放，没有空白帧或错误回退。
- 散花横向覆盖整屏，在约 1.8 秒内结束，不遮挡标题、帐篷气泡或底部组件。
- 领取、帐篷落地、底部组件进场和晚餐视频切换时间线保持正常。
- 浏览器控制台无错误。
